# AI Capstone

A personal capstone repository demonstrating AI-assisted software development workflows with Git, GitHub, and Visual Studio Code. This project is intended to document the learning process, store prompt engineering notes, and provide a clean base for future expansion.

## Project Description

This capstone explores how AI tools can enhance modern development practices. It combines documentation, planning, and workflow guidance to support a developer journey that uses AI for code design, prompts, project management, and version control.

## Goals

- Learn and document AI-assisted development workflows.
- Practice Git and GitHub collaboration and version control.
- Establish a reusable project scaffold for future enhancements.
- Capture AI prompt and planning notes in `CLAUDE.md`.

## What’s Included

- `README.md` — project overview and setup information
- `CLAUDE.md` — AI prompt notes, planning, and development guidance
- `LICENSE` — license terms
- `.gitignore` — local files to ignore in Git

## Technologies Used

- Git
- GitHub
- Visual Studio Code
- Node.js
- JavaScript

## Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/<your-username>/ai-capstone.git
   cd ai-capstone
   ```

2. Open the project in VS Code.

3. Review `CLAUDE.md` for AI prompt details and planning notes.

4. Add your capstone implementation files and update this README with progress.

## Usage

- Use `CLAUDE.md` as the central place for prompt engineering, iteration notes, and AI guidance.
- Track progress with Git commits and descriptive commit messages.
- Update the README as the project evolves, including new setup steps, dependencies, or architecture details.
